# Changelog

## 0.3.0

- Bold state: a Tap option that opens a large popup with the state and one big key to lock or unlock (or open or
  close a cover, or turn a switch on or off). Unlocking only ever happens from that key.

## 0.2.1

- Changelog headings in the format Tessera's check reads; the README notes the larger screens it is made for.

## 0.2.0

- A Label option on every tile. A changed label shows on the screen at once (Tessera remakes a tile when its
  options change, but not when only its name changes).

## 0.1.2

- The name above a value or state is bold.

## 0.1.1

- The switch shows a soft colour behind its name while on (this firmware has no card colours for plugins).

## 0.1.0

- First version: Bold value, Bold state and Bold switch tiles in bold Roboto from 32 to 108 px.
